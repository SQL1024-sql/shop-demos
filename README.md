# shop-demos

五家虛構小店的手機網站範例。客人在頁面上挑好、選好日期，最後一鍵把整理好的訂單文字傳到店家的 LINE。

**線上瀏覽：https://sql1024-sql.github.io/shop-demos/**

| 作品 | 類型 | 網址 |
|---|---|---|
| 暦菓子室 | 預約制甜點預購 | https://sql1024-sql.github.io/shop-demos/01-dessert/ |
| 鏡室 | 髮廊・美容預約 | https://sql1024-sql.github.io/shop-demos/02-salon/ |
| 河壩粄條 | 客家麵食小吃・外帶 | https://sql1024-sql.github.io/shop-demos/03-hakka-noodles/ |
| 慢郵局 | 民宿・共享空間詢問 | https://sql1024-sql.github.io/shop-demos/04-guesthouse/ |
| 小磁鐵手作教室 | 親子與成人手作課程報名 | https://sql1024-sql.github.io/shop-demos/05-craft-studio/ |
